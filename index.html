02上海寻序智能 · 计算机视觉

座舱光照辐射预测

结合车载摄像头与车机数据，分别估计驾驶位和副驾驶位的阳光辐射，为智能座舱遮阳调节提供输入，算法已应用于奇瑞、蔚来多款量产车型。

特征融合回归预测车端部署

输入与建模 从摄像头画面的不同区域提取光照特征，与车机传感器特征组合为模型输入，构建双输出回归模型，分别估计驾驶位和副驾驶位的辐射值。

训练与调优 独立完成模型搭建、训练与测试，围绕特征处理和超参数开展优化；分别检查两个座位的预测偏差，避免仅用整体表现掩盖单个座位的问题。

误差分析 针对复杂光照与动态场景，对照预测值和参考值检查误差样本，分析不同场景下的偏差，再调整特征与模型参数，复查调整后的预测表现。

部署落地 将训练后的模型导出为 ONNX，结合 INT8 量化适配车端本地运行，衔接模型输入输出与应用数据，完成从离线训练到车端推理的集成。

验证口径 项目中“MAE@100 超过 90%”表示绝对误差不超过 100 的样本占比超过 90%，用于衡量预测落入指定误差范围的情况。

03个人项目 · 3D 游戏开发

Tesla Roadster 2 模拟驾驶游戏

以 Tesla Roadster 2 为原型的非官方 3D 驾驶模拟游戏，在夜间测试场体验倒挂道路、喷气起跳与飞越车队，并可从不同机位回看完整动作。

Godot游戏物理自动化构建
GitHub 仓库 ↗

需求与开发 将玩法拆解为车辆运动、喷气控制、测试场景和动作回放模块，借助 AI 编程基于 Godot 完成开发，结合实际试玩反馈持续调整操控方式与镜头交互。

车辆与喷气 基于刚体运动处理轮地接触，用悬挂弹簧与阻尼模拟支撑和缓冲，并计算轮胎受力与路面吸附；喷气对车身施加升力和翻滚力矩，支持起跳、空中姿态调整与落地缓冲。车辆和喷气参数用于游戏玩法，不代表 Tesla 真实车辆性能。

场景与反馈 搭建弧形倒挂道路和飞越五辆车的试驾场景，支持跟车及驾驶舱视角；用喷气、轮胎和落地音效配合粒子效果，反馈车辆当前的运动状态。

回放实现 按固定时间间隔记录车辆姿态、速度与喷气等状态，回放时通过帧间插值还原运动，保留助跑至落地的动作过程；支持暂停、进度调整及自由相机，便于从不同角度检查和录制动作。

测试与交付 在 30、60、120 FPS 下回归操控输入与回放行为，检查重播、视角切换和界面显隐等交互；配置 GitHub Actions 自动测试与构建，完成 Windows 独立运行包和开源发布。

04个人项目 · iOS 应用开发

统一快递取件 App

将官方待取清单与用户导入的取件短信集中管理的 iOS 助手，统一查看待取包裹、取件凭证和历史记录，减少在不同入口反复查找信息的操作。

SwiftUIWebKit数据合并

方案与接入 先核实各平台可读取的数据及跳转方式，再基于 SwiftUI 与 WebKit 开发应用。读取用户登录后的淘宝官方待取清单，并在官方页面展示动态身份码；其他驿站保留小程序入口，按实际接入能力提供功能。

识别与去重 对用户粘贴的取件短信进行本机解析，提取快递公司、地点及取件码。优先按快递公司与完整运单号合并跨来源包裹，同时保留各来源的凭证；信息不足时采用保守匹配，存在歧义则提示补全。

状态一致性 只有完整且校验通过的官方清单才参与同步；未登录、读取失败或清单未加载完整时保留本地记录。官方清单变空只更新对应来源的待取状态，手动标记已取的包裹也不会因平台更新延迟被反复恢复。

异常与交互 针对断网或登录过期，以及微信不可用、链接失效等情况提供对应提示和恢复入口，失败时保留原绑定与包裹数据。剪贴板识别先征得用户确认，再预填导入表单；设置页逐级返回，并保存外观和语言偏好。

验证与进展 0.7.3 版本通过 62 项 Node 测试和 4 项 Python 测试，覆盖识别、合并及异常保护等逻辑，并检查网页交互。新版 iPhone 原生界面、网络行为和微信跳转仍需编译安装后验收。
